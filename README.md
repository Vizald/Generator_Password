# Генератор безопасных паролей

Консольное Python-приложение для генерации криптографически стойких паролей с гибкими настройками наборов символов и базовой оценкой надежности.

## Возможности

- Генерация паролей на базе модуля `secrets`
- Выбор классов символов:
  - строчные буквы
  - заглавные буквы
  - цифры
  - спецсимволы
- Проверка корректности пользовательского ввода
- Гарантия включения минимум одного символа из каждого выбранного класса
- Генерация нескольких паролей за один запуск
- Простая оценка надежности по длине и разнообразию символов

## Требования

- Python 3.10+ (подойдет и более новая версия)
- Внешние зависимости не требуются (используется только стандартная библиотека)

## Установка/запуск

1. Склонируйте репозиторий:

   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd Generator_Password
   ```

2. Запустите программу:

   ```bash
   python secure_password_generator.py
   ```
